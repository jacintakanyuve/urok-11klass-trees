Деревья. Иерархические структуры данных

Дерево — важнейшая нелинейная иерархическая структура данных в информатике. На основе деревьев организованы файловые системы операционных систем, объектная модель веб-страниц (DOM), префиксные коды сжатия данных (коды Хаффмана), индексы баз данных и деревья принятия решений в искусственном интеллекте.

1. Определение дерева и терминология иерархических структур

С точки зрения теории графов дерево — это связный неориентированный граф без циклов. Между любыми двумя вершинами дерева существует единственный простой путь, а количество рёбер всегда на 1 меньше количества вершин:

Фундаментальное свойство дерева:   |E| = |V| − 1

В программировании чаще всего используют корневые (ориентированные) деревья, в которых выделена главная начальная вершина, а связи направлены сверху вниз — от предков к потомкам:

Корень (Root) Единственная вершина на самом верхнем уровне (уровень 0), не имеющая родителя.
Лист (Leaf) Терминальная вершина, у которой нет ни одного потомка (ребёнка).
Внутренний узел Вершина, имеющая хотя бы одного потомка. Любой узел вместе со всеми его потомками образует поддерево.

Глубина (уровень) узла — длина пути от корня до этого узла (у корня глубина равна 0). Высота дерева (h) — максимальная глубина среди всех его листьев.

2. Бинарные деревья и алгоритмы обхода (DFS)

Бинарное (двоичное) дерево — это корневое дерево, в котором каждый узел имеет не более двух потомков, строго различаемых как левый и правый.

Максимум узлов на уровне k: 2k  |  Максимум узлов в бинарном дереве высоты h: Nmax = 2h+1 − 1
Бинарное дерево поиска (Binary Search Tree, BST):
Особый вид бинарного дерева, упорядоченный по ключу: для каждого узла X все ключи в его левом поддереве меньше ключа X, а все ключи в его правом поддереве больше ключа X. Позволяет выполнять поиск за логарифмическое время $O(\log_2 N)$.

Три классических способа обхода дерева в глубину (DFS):

  • Прямой обход (Pre-order: Корень → Левое → Правое): сначала обрабатывается сам узел, затем его левое и правое поддеревья. Используется для копирования структуры дерева.
  • Симметричный обход (In-order: Левое → Корень → Правое): для бинарного дерева поиска выводит все ключи строго в порядке возрастания!
  • Обратный обход (Post-order: Левое → Правое → Корень): сначала обрабатываются потомки, затем родитель. Используется для безопасного удаления дерева из памяти и вычисления арифметических выражений.

3. Представление деревьев в памяти и рекурсивная обработка

В программах на языке Python деревья удобно хранить в виде словаря списков смежности (где каждому узлу сопоставлен список его прямых потомков) или с помощью классов/кортежей. Благодаря древовидной структуре любые вычисления на деревьях естественно записываются рекурсивно:

tree = { 'A': ['B', 'C'], 'B': ['D', 'E'], 'C': ['F'], 'D': [], 'E': ['G', 'H'], 'F': [], 'G': [], 'H': [] } # Рекурсивный подсчёт количества листьев в поддереве node def count_leaves(node): if len(tree[node]) == 0: # Базовый случай: узел является листом return 1 return sum(count_leaves(child) for child in tree[node]) print(count_leaves('A')) # Вывод: 4 (листья: D, G, H, F)
